# Benchmarks

Source: the MedQGraph paper, section 6, Table 1 and Appendix A.

All figures come from the project's own Medication / Diagnosis / Risk Assessment
query benchmark, derived from MIMIC-IV, **n = 50**. It is an internal benchmark,
not a community-adopted one, which is the main limit on comparing these results
to published work.

## Query latency: Neo4j against a SQL baseline

The baseline is SQL queries run against the structured MIMIC-IV tables — the
same questions, answered the way they would be without the graph.

| Query | SQL (ms) | Neo4j (ms) | Speedup | Reduction |
|---|---|---|---|---|
| Patient medications | 450 | 158 | 2.85x | 65% |
| Medical history | 520 | 182 | 2.86x | 65% |
| Procedure risks | 380 | 133 | 2.86x | 65% |
| Diagnosis patterns | 610 | 213 | 2.86x | 65% |
| **Average** | **490** | **172** | **2.85x** | **65%** |

## Pipeline quality

| Measure | Result | How it was judged |
|---|---|---|
| Natural-language to Cypher | 94.3% convert to valid Cypher | automatic validation |
| Summary quality | 89.7% accurate and clinically appropriate | clinical-expert review |
| Follow-up suggestions | 82.1% clinically useful | rated |
| Query-to-insight time | ~8.5 min to ~15 s | manual EHR navigation vs the system |

Two of these are easy to state loosely and shouldn't be. **94.3% is a
natural-language-to-Cypher conversion rate**, not an end-to-end answer accuracy.
And the **8.5 minutes is a human navigating EHR screens**, not the SQL baseline —
the SQL comparison is the millisecond table above.

## Cypher generation across open models

Four open models were scored against ground-truth queries generated by GPT-4o,
using BLEU (syntactic similarity), edit distance (structural proximity), TF-IDF
(content overlap) and ROUGE (n-gram recall).

| Model | BLEU | Edit distance | TF-IDF | ROUGE |
|---|---|---|---|---|
| Qwen 2.5 7B | **0.2512** | 0.6879 | **0.7765** | **0.6667** |
| Gemma 3 4B | 0.1774 | **0.8716** | 0.8182 | 0.5714 |
| Mistral 7B | 0.0954 | 0.6214 | 0.5562 | 0.4762 |
| Llama 3.2 | 0.1383 | 0.7598 | 0.6698 | 0.5000 |

The references are GPT-4o's own queries, so these scores measure agreement with
GPT-4o's query style rather than clinical correctness. The paper says so.

## Context from the literature

Appendix A, Table 6 places three published systems beside the baseline. **Those
rows are projected from the cited papers, not run on this benchmark** — different
hardware, different query sets, different prompts. They are context for the
field's reported ranges, not a head-to-head comparison. Only the SQL baseline
and MedQGraph rows share a benchmark and a metric.

| System | Medication | Diagnosis | Risk assessment | Avg time |
|---|---|---|---|---|
| Medical Graph RAG (Wu et al. 2025)* | 208 ms / 94.1% | 231 / 92.5 | 187 / 91.6 | -54% |
| GraphRAG (Edge et al. 2024)* | 267 / 90.3 | 298 / 88.7 | 241 / 87.9 | -37% |
| MedRAG (Xiong et al. 2024)* | 312 / 87.5 | 341 / 85.9 | 286 / 84.6 | -24% |
| SQL baseline | 450 / 71.2 | 520 / 66.8 | 380 / 62.1 | baseline |
| **MedQGraph** | **158 / 96.2** | **182 / 93.8** | **133 / 92.4** | **-65%** |

\* projected/illustrative, not evaluated here.

## Limitations

From the paper, unabridged, because they are what make the numbers above
trustworthy:

- MIMIC-IV is a single institution's critical-care database (Beth Israel
  Deaconess). Generalisation to other EHR systems, coding conventions and patient
  populations is not established.
- The latency and accuracy figures come from an internal benchmark, not a
  standardised clinical QA benchmark, which limits comparison with prior work.
- LLM-generated Cypher and summaries can propagate model errors or hallucinated
  relationships. Schema and syntax validation runs before execution, but it does
  not guarantee the query means what the user intended.
- The system depends on GPT-4o through an API, which raises data-governance
  questions for any real clinical deployment as opposed to research use on
  de-identified data.
- The open-model comparison is scored against GPT-4o references rather than
  clinician-verified ground truth.

Prospective clinical validation, usability evaluation and bias auditing all
remain to be done. Nothing here is clinically ready.
